# TriPulse – Firebase + GitHub Pages setup (owner-only) ## 1. Create the Firebase project 1. https://console.firebase.google.com → **Add project** (Analytics not needed). 2. **Build → Authentication → Get started → Sign-in method**: enable **Google** only (leave Email/Password off). 3. **Build → Firestore Database → Create database** (production mode, any region). 4. **Firestore → Rules** → paste this (replace `YOU@gmail.com` with your Google address) → **Publish**. Only your verified Google account can read or write; everyone else is rejected by the server: ``` rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /tripulse/{uid} { allow read, write: if request.auth != null && request.auth.uid == uid && request.auth.token.email == 'YOU@gmail.com' && request.auth.token.email_verified == true; } } } ``` 5. **Project settings (gear) → Your apps → Web ()** → register an app → copy the `firebaseConfig` object. ## 2. Put your details in the file Open `tripulse.html` in a text editor and fill in two lines near the cloud-sync code (search for `FIREBASE_CONFIG`): - `const FIREBASE_CONFIG={ ...paste your firebaseConfig... };` - `const ALLOWED_EMAIL='YOU@gmail.com';` Both are safe to publish – the Firebase config is not a secret; the rules above and the email check protect your data. With these set, the app shows a **"TriPulse is private"** sign-in screen to everyone and only opens for your Google account. ## 3. Host on GitHub Pages 1. Create a GitHub repository (e.g. `tripulse`) and upload the edited file, renamed **`index.html`**. 2. **Settings → Pages → Build and deployment**: *Deploy from a branch*, `main`, `/ (root)` → Save. 3. Your app is at `https://.github.io/tripulse/`. ## 4. Allow sign-in from that address Firebase → **Authentication → Settings → Authorized domains → Add domain** → `.github.io`. ## 5. First sign-in, then lock the door 1. Open your Pages URL → **Sign in with Google** with the account in `ALLOWED_EMAIL`. 2. In Firebase → **Authentication → Settings → User actions**, untick **Enable create (sign-up)** so no new accounts can ever be created. 3. Click **⚙ Connect** and enter your intervals.icu Athlete ID and API key (or tick "Also sync my intervals.icu Athlete ID & API key" under **☁ Cloud** so new computers connect automatically). ## Notes - If someone signs in with a different Google account they are signed straight back out ("Access denied") and the server rejects any read or write. - Changing the page itself is limited by who can edit your GitHub repo, so keep your GitHub account secured with 2-factor authentication. - The page contains no passwords. Your intervals.icu key is only stored in your browser, and in your private Firestore document only if you tick the sync option.
